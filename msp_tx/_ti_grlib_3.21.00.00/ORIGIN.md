# Origin

**TI MSP430 Graphics Library (grlib), version 3.21.00.00**, extracted from
**MSP430Ware 3.80.14.01**, with the font sources merged into `fonts/`.

This is the LAST version ever published by TI for MSP430: frozen == current
(verified against MSP430Ware 3.80.14.01 in July 2026).

The function documentation lives as doxygen comments above each definition in
the `.c` sources; it is extracted into the searchable `sdk_reference.html` at
the root of this SDK.
